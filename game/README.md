# Ордо (прототип)

Прототип стратегии про XVIII век: оседлые против кочевников. Два режима:

- **Город (демо)** — за любую сторону:
  - **Коканд.** Отстраиваете город как в «Казаках»: деҳқоны добывают дерево, камень, золото и еду,
    вы строите дома, поля, мельницу, склады, казарму, конюшню и пушечный двор, нанимаете войска по одному.
    С севера идут набеги кыпчаков; победа — разрушить их Хан ордосу, поражение — потерять Урду.
  - **Кыпчаки.** Кочевой лагерь из юрт. Его можно свернуть в арбы, перевезти и поставить в другом месте:
    кончилось золото или вытоптана трава — снимаетесь и уходите (көч). С севера наступает кокандское войско;
    поражение — потерять Хан ордосу (или арбу с ним в пути).

  Юзбоши / жүз башы (офицер) собирает до 100 бойцов одного рода в отряд.
- **Сражение.** Готовые армии Коканда и кыпчаков, бой против компьютера.

## Город: здания

| Здание | Стоит | Что даёт |
|---|---|---|
| Урда | есть с начала | обучает деҳқонов, принимает все ресурсы, +25 населения |
| Уй | 80 дерева, 20 камня | +15 населения |
| Дала | 60 дерева | поле на 4 деҳқонов, бесконечная еда |
| Тегирмон | 120 дерева | сюда носят урожай |
| Омбор | 100 дерева | склад дерева, камня и золота |
| Казарма | 200 дерева, 100 камня | сарбозы, камончилар, найзачилар, киличбозлар, юзбоши |
| Отхона | 220 дерева, 60 камня | навкары, юзбоши |
| Тўпхона | 200 дерева, 200 камня, 100 золота | зарбзаны |

Войско ест еду (около 0,7 в минуту на бойца). Если еда кончится, солдаты начнут слабеть.
Компьютер пока не ведёт настоящую экономику: набеги приходят по таймеру и растут со временем.

## Город: лагерь кыпчаков

Все постройки — юрты и загоны из дерева и золота, камень кочевникам не нужен.

| Постройка | Стоит | Что даёт |
|---|---|---|
| Хан ордосу | есть с начала | обучает малчы, принимает все ресурсы, +25 населения; сворачивает весь лагерь |
| Боз үй | 40 дерева, 12 с | +10 населения |
| Короо | 60 дерева | отара сама даёт еду, пока вокруг есть трава; трава вытаптывается и медленно отрастает |
| Кен | 80 дерева | стан у золота или камня: склад рядом с жилой, добыча +50% |
| Жоокер үйү | 120 дерева | жөө жоокерлер, мергендер, жүз башы |
| Жылкы короосу | 150 дерева, 40 золота | атчан жаачылар, чабуулчулар, сайыскерлер, жүз башы |
| Курултай | 200 дерева, 150 золота | батырлар |

**Сильные стороны:** лагерь мобилен; отары кормят без полей и мельниц; юрты дешёвые и ставятся быстро;
за убитых врагов и разорённые здания идёт олжо (добыча: золото, еда, дерево).
**Слабые:** юрты хрупкие, трава кончается, пушек нет.

**Көч (переезд):**
1. Выберите Хан ордосу → «Көч: свернуть весь лагерь» (Shift+K). Все юрты в радиусе 170 м складываются в арбы.
2. ПКМ — арбы едут на новое место (арба с Хан ордосу — главная, берегите её).
3. «Развернуть лагерь» (K) → ЛКМ по земле: юрты встают кольцом вокруг точки.

Отдельную юрту можно свернуть кнопкой «Свернуть в арбу» (K) и поставить где угодно.

## Армии

| Коканд | Кыпчаки |
|---|---|
| Камончилар — пешие лучники (125 м, 24 стрелы) | Атчан жаачылар — конные лучники (100 м, 15 стрел, потом сабли) |
| Найзачилар — копейщики, держат натиск | Жөө жоокерлер — пехота с мечом и щитом |
| Киличбозлар — мечники со щитами | Мергендер — меткие пешие стрелки (135 м) |
| Навкарлар — конница с саблями | Сайыскерлер — тяжёлые копейщики |
| Хос навкарлар + лашкарбоши — сверхтяжёлая гвардия | Чабуулчулар — лёгкая конница для налётов |
| | Батырлар + колбашчы — сверхтяжёлая гвардия |

- **Выносливость.** Бег и галоп её тратят, кони устают быстрее всех. Уставший отряд медленнее и бьёт слабее, натиск без сил не выходит.
- **Стрелы и рукопашная.** Когда стрелы кончаются, отряд сам берётся за сабли; клавиша R переключает это вручную.
- **Командир.** Поднимает мораль отрядов рядом, раз в 75 секунд может крикнуть боевой клич (V): дух и силы отрядов рядом растут. Если командир погибнет, мораль всей армии падает.
- **Щиты** вдвое ослабляют стрелы.
- **Звук** синтезируется в браузере: кличи «Ур-раа!» и «Ураан!», карнай и рог, звон клинков, свист стрел, топот.

## Как запустить

Нужен любой локальный веб-сервер (модули не грузятся с `file://`):

```bash
cd game
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Управление

| Действие | Клавиши |
|---|---|
| Выбрать отряд или здание | ЛКМ; рамкой — несколько; двойной клик — все такие же на экране |
| Добывать / строить (город) | выбрать деҳқонов, ПКМ по лесу, камню, золоту, полю или стройке |
| Построить (город) | деҳқоны → кнопка здания → ЛКМ на карте (Shift — несколько) |
| Сборный пункт (город) | выбрать здание, ПКМ по земле или ресурсу |
| Собрать / распустить отряд (город) | юзбоши + бойцы одного рода → U |
| Свернуть юрту / весь лагерь (кыпчаки) | выбрать юрту → K / Хан ордосу → Shift+K |
| Развернуть лагерь из арб (кыпчаки) | выбрать арбы → K → ЛКМ на карте |
| Свободный работник | . |
| Идти / атаковать | ПКМ по земле / по врагу |
| Выстроить линию | ПКМ и протянуть |
| Бегом / галопом | двойной ПКМ |
| Стрельба / рукопашная | R |
| Боевой клич командира | V |
| Строй (линия, колонна, каре, рассыпной) | F |
| Стоп | H |
| Качып атуу (всадники-лучники отходят и стреляют) | G |
| Группы | Ctrl+1…9, затем 1…9 (дважды — камера к группе) |
| Камера | WASD / стрелки / края экрана, колесо, Q/E, средняя кнопка |
| Пауза, скорость, звук | P, + / −, M |

## Баланс

`npm run balance` прогоняет 20 боёв «компьютер против компьютера» в Node и печатает,
сколько выиграла каждая сторона. Параметры юнитов — в `src/units.js`.
