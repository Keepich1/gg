# Ордо · поле боя (прототип)

Играбельный прототип стратегии про XVIII век: оседлые против кочевников.
Сейчас это только сражение: **Коканд против кыпчаков**, игрок против компьютера.
Экономики, построек и мультиплеера пока нет: сначала проверяем бой, управление и масштаб.

## Армии

| Коканд | Кыпчаки |
|---|---|
| Камончилар — пешие лучники (125 м, 24 стрелы) | Атчан жаачылар — конные лучники (100 м, 15 стрел, потом сабли) |
| Найзачилар — копейщики, держат натиск | Жөө жоокерлер — пехота с мечом и щитом |
| Киличбозлар — мечники со щитами | Мергендер — меткие пешие стрелки (135 м) |
| Навкарлар — конница с саблями | Сайыскерлер — тяжёлые копейщики |
| Хос навкарлар + лашкарбоши — сверхтяжёлая гвардия | Чабуулчулар — лёгкая конница для налётов |
| | Батырлар + колбашчы — сверхтяжёлая гвардия |

- **Выносливость.** Бег и галоп её тратят, кони устают быстрее всех. Уставший отряд медленнее и бьёт слабее, натиск без сил не выходит.
- **Стрелы и рукопашная.** Когда стрелы кончаются, отряд сам берётся за сабли; клавиша R переключает это вручную.
- **Командир.** Поднимает мораль отрядов рядом, раз в 75 секунд может крикнуть боевой клич (V): дух и силы отрядов рядом растут. Если командир погибнет, мораль всей армии падает.
- **Щиты** вдвое ослабляют стрелы.
- **Звук** синтезируется в браузере: кличи «Ур-раа!» и «Ураан!», карнай и рог, звон клинков, свист стрел, топот.

## Как запустить

Нужен любой локальный веб-сервер (модули не грузятся с `file://`):

```bash
cd game
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Управление

| Действие | Клавиши |
|---|---|
| Выбрать отряд | ЛКМ по солдатам или по карточке внизу; рамкой — несколько; двойной клик — все такие же на экране |
| Идти / атаковать | ПКМ по земле / по врагу |
| Выстроить линию | ПКМ и протянуть |
| Бегом / галопом | двойной ПКМ |
| Стрельба / рукопашная | R |
| Боевой клич командира | V |
| Строй (линия, колонна, каре, рассыпной) | F |
| Стоп | H |
| Качып атуу (всадники-лучники отходят и стреляют) | G |
| Группы | Ctrl+1…9, затем 1…9 (дважды — камера к группе) |
| Камера | WASD / стрелки / края экрана, колесо, Q/E, средняя кнопка |
| Пауза, скорость, звук | P, + / −, M |

## Баланс

`npm run balance` прогоняет 20 боёв «компьютер против компьютера» в Node и печатает,
сколько выиграла каждая сторона. Параметры юнитов — в `src/units.js`.

## Устройство

| Файл | Что внутри |
|---|---|
| `src/world.js` | карта 1,6 × 1,6 км: рельеф, река, горы |
| `src/units.js` | юниты, фракции, стартовые армии, построения |
| `src/sim.js` | симуляция боя: движение, выносливость, рукопашная, стрельба, натиск, мораль, командиры |
| `src/audio.js` | синтезированный звук боя |
| `src/ai.js` | компьютерный противник |
| `src/terrain.js` | 3D-рельеф, вода, лес, небо |
| `src/render.js` | модели и эффекты: солдаты, кони, гвардия, командиры, знамёна, стрелы, пыль |
| `src/camera.js`, `src/input.js`, `src/hud.js`, `src/main.js` | камера, управление, интерфейс, главный цикл |
| `vendor/three.module.min.js` | Three.js r169 (MIT) |
