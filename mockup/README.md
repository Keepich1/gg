# Ордо — макет игрового кадра

Статичный макет одного кадра будущей стратегии в духе Stronghold Crusader
с центральноазиатским сеттингом: крепость Шёлкового пути против ставки кочевников.

Откройте `index.html` в браузере (сервер не нужен).

- **Сезон** (Жай / Күз / Кыш) меняет палитру мира: золотые тополя осенью, снег зимой.
- **Сторона** (Шаар / Көчмөн) переключает интерфейс: ресурсы, меню построек, отряд, героя.
- **Экран** (ПК / Телефон) показывает компактную раскладку для смартфона.
- Карту можно тянуть мышью или пальцем, колесо и щипок меняют масштаб.
- Карточки в меню построек ставят «призрак» здания на карту.

Вся графика рисуется кодом на Canvas 2D, картинок нет.

| Файл | Что внутри |
|---|---|
| `iso.js` | изометрия, цвета, сезоны, примитивы (блок, цилиндр, купол) |
| `world.js` | раскладка карты: рельеф, река, арыки, крепость, ставка, стада |
| `draw.js` | небо, земля, здания и деревья (статичный слой) |
| `fx.js` | анимация: люди, кони, дым, вода, снег, выделение отряда |
| `hud.js` | интерфейс, камера, мини-карта, управление |
